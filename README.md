# go-univocity

Authoritative reference implementation for **leaf commitment** and **PublishGrant** (grant) encoding, aligned with the [univocity](https://github.com/forestrie/univocity) Solidity contracts and [canopy](https://github.com/forestrie/canopy) grant format.

## Purpose

- Single source of truth for the hashing and grant formats used when appending authority log leaves and when building grants for `publishCheckpoint`.
- Go package: `LeafCommitment`, grant encode/decode; consumable by arbor services (queue consumer, ranger).
- Test vectors generated by `tests/scripts/gen_testvectors.py` for Go, TypeScript, and Python.

## Documentation

- **[docs/grant-and-leaf-format.md](docs/grant-and-leaf-format.md)** — Hashing (leaf commitment) and grant format spec; encoding/decoding examples in Go, TypeScript, and Python.

## Usage

```go
import "github.com/forestrie/go-univocity/grant"

leafHash := grant.LeafCommitment(idTimestampBE, logId, grantFlags, maxHeight, minGrowth, ownerLogId, grantData)
```

## Tests

```bash
go test ./...
```

Generate test vectors (requires Python 3):

```bash
python3 tests/scripts/gen_testvectors.py
```
